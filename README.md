# وب‌سایت شخصی محمدامین

این پروژه، وب‌سایت پورتفولیوی شخصی من است که با استفاده از HTML، CSS و JavaScript خالص (Vanilla) طراحی و توسعه یافته است.

## ویژگی‌ها
- طراحی مدرن و واکنش‌گرا (Responsive)
- رابط کاربری با تم تاریک و افکت‌های نئونی
- بهینه‌سازی شده برای موتورهای جستجو (SEO)
- سرعت بالا و بدون استفاده از فریم‌ورک‌های سنگین
